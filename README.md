# نظام تدبير وتوثيق مهام التفتيش والمراقبة
## Inspector Missions Management System

تطبيق سحابي متكامل ومتزامن بالزمن الفعلي لإدارة، توثيق، وتتبع مهام المفتشين التربويين والمرافقين عبر الحاسوب والأجهزة الذكية.

---

### ✨ المميزات الرئيسية (Key Features)

- **تسجيل شامل لبيانات المهمة**:
  - إسم السيد المفتش، رقم التأجير، نوع المهمة، التاريخ.
  - إمكانية تحديد حتى 3 وجهات/مؤسسات تفتيشية في مهمة واحدة.
  - تسجيل حتى 3 مرافقين مع أرقام تأجيرهم أو أسمائهم.
  - تدوين الملاحظات التوجيهية وتحديد حالة المهمة (منجزة، جارية، مبرمجة).
- **مزامنة فورية متعددة الأجهزة (Real-Time Live Sync)**:
  - مزامنة سحابية بالزمن الحقيقي عبر Server-Sent Events (SSE).
  - استخدام متزامن بين الحاسوب، الهاتف الذكي، والأجهزة اللوحية دون فقدان البيانات.
- **تصدير وطباعة متقدمة**:
  - تصدير فوري إلى جداول Excel (`.xlsx`) بتنسيق منظم.
  - تصدير بصيغة CSV (ترميز UTF-8 مع BOM) متوافق مع كافة البرامج.
  - تقارير طباعة رسمية جاهزة مع دعم الحفظ المباشر كملف PDF.
  - نسخ احتياطي متكامل بصيغة JSON.
- **تكامل مباشر مع GitHub**:
  - الاتصال بحساب GitHub عبر Personal Access Token.
  - إنشاء مستودعات جديدة تلقائياً من داخل التطبيق (عامة أو خاصة).
  - رفع كامل شفرة المشروع (Full Project Codebase) بضغطة زر واحدة.
  - حفظ ومزامنة قاعدة بيانات المهام (`missions.json`) دورياً إلى المستودع.
- **واجهة مستخدم عصرية**:
  - دعم كامل للغتين والنمطين (الوضع الداكن والوضع الفاتح).
  - عرض جدول منظم أو بطاقات تفاعلية مع إحصائيات فورية (KPIs).

### 🚀 التشغيل والتثبيت محلياً (Local Setup)

```bash
# 1. استنساخ المستودع
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>

# 2. تثبيت الحزم البرمجية
npm install

# 3. تشغيل خادم التطوير
npm run dev
```

التطبيق سيعمل محلياً على: `http://localhost:3000`

---

### 📦 حزمة التقنيات المستخدمة (Tech Stack)

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Lucide React, Motion.
- **Backend**: Node.js, Express, Server-Sent Events (SSE), GitHub REST API.
- **Data Persistence**: JSON Storage with Real-Time File System Syncing & Cloud Export.
